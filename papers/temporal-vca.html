Temporal-VCA: Simulating urban land use change using coupled temporal data and vector cellular automata

Yao Yao, Kun Zhou, Chenxi Liu, Zhenhui Sun, Dongsheng Chen, Linlong Li, Tao Cheng, Qingfeng Guan

Cities · 2024

DOI: 10.1016/j.cities.2024.104975 · ISSN: 0264-2751

Paper DOI Code

Abstract

Temporal-VCA extends the vector cellular automata framework by coupling temporal data to simulate urban land use change, capturing dynamic spatiotemporal patterns with improved accuracy for urban planning applications.
