# 👋 Hi, I'm Zhenhui Sun (孙振辉)

I received my master's degree in GIS from East China Normal University and currently work at Tencent as a software engineer. My research interests include geospatial big data mining, geographic simulation models, sustainable development assessment, and related software tool development. I am currently exploring the integration of geography and AI to enhance geospatial workflows and build more intelligent tools for geographic analysis and applications.
